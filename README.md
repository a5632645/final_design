# digital waveguide synthesizer/数字波导合成器  
This is a MPE capability digital waveguide synthesizer.It has plucked, woodwind and bowed engine.Or you can use it as a MPE midi keyboard(only one octave).  
这是一个mpe兼容的数字波导合成器，有拨弦，木管和弓弦模型，也可以当成mpe键盘使用，尽管只有一个八度。
